# Bouquet for Denichka

A 3D bouquet built with Three.js. Peonies, roses, tulips, daisies and baby's breath bloom one by one, then the dedication writes itself across the top. Drag to turn the bouquet.

Everything is in `index.html`. Three.js and the fonts load from a CDN, so the page needs an internet connection.

## Run it

Open `index.html` in a browser, or serve it with Docker:

```bash
docker compose up -d
```

Then open http://localhost:8080.

Docker is optional. The page is a single static file and works on any static host, such as GitHub Pages.
